# Диалоговый бот с памятью

Телеграм-помощник отвечает на сообщения и хранит сведения о пользователе в векторной базе Pinecone. Перед записью бот считает косинусное сходство нового текста с уже сохранёнными фрагментами этого человека.

## Как устроена память

Граница сходства задаётся в начале `pinecone_manager.py` переменной `COSINE_SIMILARITY_THRESHOLD` (сейчас `0.85`).

- Сходство ниже границы — новая информация, создаётся новый слот памяти.
- Сходство на границе или выше и текст тот же — дубликат, запись пропускается.
- Сходство высокое, но формулировка другая — обновляется существующий слот.

Память разных пользователей не смешивается: поиск и запись фильтруются по `user_id`.

## Файлы

| Файл | Назначение |
| --- | --- |
| `bot.py` | Телеграм-бот на pyTelegramBotAPI |
| `pinecone_manager.py` | Чтение, запись и решение, что запоминать |
| `requirements.txt` | Зависимости |

Команда `/start` только приветствует. Обычные текстовые сообщения попадают в диалог и в память.

## Запуск

Нужны Python 3.11+, ключи OpenAI, Pinecone и Telegram. Индекс Pinecone должен уже существовать и совпадать по размерности с моделью `text-embedding-3-small` (1536).

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

Создайте файл `.env` рядом с `bot.py`:

```
OPENAI_API_KEY=
OPENAI_CHAT_MODEL=gpt-4o-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
PINECONE_API_KEY=
PINECONE_INDEX_NAME=
PINECONE_NAMESPACE=
TELEGRAM_BOT_TOKEN=
```

Запуск бота:

```bash
python bot.py
```

Файл `.env` в репозиторий не входит.
